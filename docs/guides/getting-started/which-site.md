# Which site do I use?

Every service has its own address. All of them are also on the home page at <https://f9.casa>.

| Service         | Address                     | What it's for                                | Sign in with      |
| --------------- | --------------------------- | -------------------------------------------- | ----------------- |
| Home page       | <https://f9.casa>           | Buttons for everything                       | House login       |
| Jellyfin        | <https://jellyfin.f9.casa>  | Films and TV                                 | Jellyfin account  |
| Seerr           | <https://requests.f9.casa>  | Request films and shows ("Requesting media") | Own account (ask) |
| Music Assistant | <https://music.f9.casa>     | Music on the speakers                        | Own account (ask) |
| Immich          | <https://photos.f9.casa>    | Photos and videos                            | Immich account    |
| Zipline         | <https://i.f9.casa>         | Share files and images by link               | House login       |
| Paperless       | <https://docs.f9.casa>      | Scanned documents                            | House login       |
| Home Assistant  | <https://home.f9.casa>      | Smart home                                   | House login       |
| Homebox         | <https://inventory.f9.casa> | What we own and where it is                  | House login       |
| Bambuddy        | <https://bambuddy.f9.casa>  | 3D printer control                           | House login       |
| Open WebUI      | <https://ai.f9.casa>        | AI chat                                      | House login       |
| Private search  | <https://search.f9.casa>    | Search without tracking                      | None              |
| Status page     | <https://status.f9.casa>    | Is everything up?                            | None              |

!!! note "House login"
"House login" means the shared Authelia account described in [Your account](your-account.md).
Some apps (Jellyfin, Immich, Seerr, Music Assistant) keep their own accounts. If you don't have one, ask.
