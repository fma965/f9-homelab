# Is something down?

**Address:** <https://status.f9.casa>

The status page checks our services all the time and shows which are working (green) and which are not (red).

## What to do

1. Open the status page and find the service you're trying to use.
2. If it's **red**, the problem is on our side. The person who runs the server is usually told automatically, so you don't need to do anything. Try again later.
3. If it's **green** but it still doesn't work for you, see [Troubleshooting](troubleshooting.md).
