# 3D printing

We have a Bambu Lab 3D printer. Two sites help with it.

## Bambuddy: print queue and control

**Address:** <https://bambuddy.f9.casa>

Use Bambuddy to see the printer's status, queue prints and watch progress. Sign in with your house login.

## Spoolman: filament tracker

**Address:** <https://spoolman.f9.casa>

Spoolman keeps track of every spool of filament: colour, type and how much is left. When you load a new spool, add it here so the next person knows what is available.

## Before you print

1. Check that the filament you need is loaded (see Spoolman).
2. Check the build plate is clear and clean.
3. Start the print and don't leave it running unattended for long jobs.

!!! warning "Never leave a long print unattended"
3D printers get hot. If you see anything strange (smoke, a smell, noise), stop the print and switch it off at the wall.
