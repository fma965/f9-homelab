# Games Manager

**Address:** <https://games.f9.casa>

Games Manager is a catalogue of our game collection, so we can see what we own and avoid buying the same game twice.

## Using it

1. Open the site and choose **F9 Auth** to sign in with your house login.
2. Browse or search the collection.
3. Open a game to see its details.

!!! note "Admin side"
    The database behind it (`gamesdb.f9.casa`) is only for Scott. If a game is missing or wrong, tell Scott.
