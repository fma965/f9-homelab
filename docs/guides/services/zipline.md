# Sharing files & screenshots (Zipline)

**Address:** <https://i.f9.casa>

Zipline turns a file or image into a **link** you can send to anyone, which is handy when it's too big for a message.

## Share a file

1. Open the site and sign in with your house login.
2. Drag the file in (or press the upload button).
3. Copy the link it gives you and send it.

## Tips

- Links work for people outside the house, so only share things you're happy for them to see.
- You can delete an upload any time from your file list and its link stops working.
- Great for screenshots and videos.
