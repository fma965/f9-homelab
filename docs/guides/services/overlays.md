# Stream overlays

**Address:** <https://overlays.f9.casa>

Overlays are web pages used as graphics on top of a live stream or recording in OBS, such as a game-challenge tracker. You don't need to sign in.

## Using one in OBS

1. In OBS add a **Browser** source.
2. Paste the address of the overlay you want.
3. Set the width and height to match your scene.

!!! note
    Some overlays need the websocket server to be running (`ws.f9.casa`). If an overlay shows but doesn't update, tell Scott.

You only need this if you stream or record. Everyone else can ignore it.
