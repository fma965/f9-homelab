# Smart home (Home Assistant)

**Address:** <https://home.f9.casa>

Home Assistant controls the smart devices in the house: lights, heating, plugs, sensors and cameras.

## On your phone

1. Install the **Home Assistant** app.
2. When asked for the server address, enter `https://home.f9.casa`.
3. Sign in.

Using the app also lets the house know when you're home, which some automations use.

## What you can do

- Turn lights and plugs on or off, and change colours and brightness.
- Check or change the heating.
- See temperatures and other sensors.
- Run scenes, such as "movie time", if they are set up.

## Automations

Lots of things happen automatically, such as lights switching on at dusk. If something does something unexpected, tell the person who runs the server rather than changing settings.

!!! warning "Please don't edit automations"
Changing automations or settings can break things for everyone. Dashboards and device controls are safe to use.
